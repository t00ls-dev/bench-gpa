# Code Review

Quando utilizada:

Faça uma revisão completa considerando:

- bugs
- code smells
- duplicação
- legibilidade
- complexidade
- performance
- TypeScript
- React

Classifique cada problema:

- Crítico
- Alto
- Médio
- Baixo

Sempre explique:

- por que é um problema;
- como corrigir;
- impacto da correção.
