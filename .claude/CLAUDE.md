# Bench GPA

## Objetivo

Bench GPA é uma aplicação para análise operacional de lojas do GPA.

## Stack

- Lovable
- React
- TypeScript
- TanStack Start
- Supabase
- PostgreSQL
- Tailwind CSS

## Princípios

- Priorizar segurança antes de novas funcionalidades.
- Nunca sugerir desabilitar RLS.
- Preferir soluções simples.
- Evitar duplicação de código.
- Manter tipagem forte em TypeScript.
- Sempre considerar impacto de performance.

## Ao revisar código

Analise:

- Bugs
- Segurança
- Performance
- Legibilidade
- Manutenibilidade

Ao sugerir alterações:

- Explique o motivo.
- Mostre riscos.
- Sugira alternativas quando fizer sentido.
